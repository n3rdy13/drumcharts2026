Torn - Natalie Imbruglia - 96.3 BPM - F — DAW session exported from MusicMastering
======================================================================

Every file in Stems/ starts at exactly 0:00. Drop them all at the very
start of a session and they line up — including your recorded takes.

  Stems/                    one WAV per track, all aligned to 0:00
  Torn - Natalie Imbruglia - 96.3 BPM - F.rpp           Reaper — open directly
  Torn - Natalie Imbruglia - 96.3 BPM - F.dawproject    Cubase 14+, Studio One 6.5+, Bitwig, Cubasis — open directly

Tempo: 96.3 BPM    Key: F
The MIDI file carries the song's real beat grid, so the bar ruler follows the recording. Chord changes come in as markers.

Pro Tools
  1. New session, then drag everything from Stems/ into the timeline
     and spot each clip to 0:00 (Shuffle off, Spot mode is easiest).
  2. File > Import > MIDI, choose Torn - Natalie Imbruglia - 96.3 BPM - F.mid and enable
     "Import Tempo Map From MIDI File" — markers come along too.

Logic Pro
  1. Drag the Stems/ files into an empty project at bar 1.
  2. File > Import > MIDI File with Torn - Natalie Imbruglia - 96.3 BPM - F.mid; when Logic asks,
     import the tempo.

Ableton Live
  1. Drag the Stems/ files into Arrangement view at 1.1.1 and switch
     Warp off on the clips so they keep their true length.
  2. Drag Torn - Natalie Imbruglia - 96.3 BPM - F.mid into the set to bring the tempo across.

If a DAW that opens .dawproject cannot find the audio, keep the
.dawproject file next to the Stems folder (as unzipped) — it references
the WAVs there.
